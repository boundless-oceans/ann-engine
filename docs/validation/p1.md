## 性能范围与局限

最新固定 P 核 L2/128 同轮 CPU mean：Scalar 52.5321 ns、AVX2Four 5.1699 ns，约 10.16×，
在这个已测场景达到设计中的 ≥4× 要求。环境：i7-14650HX（16 核/24 线程）、Ubuntu 22.04.5、
GCC 11.4 RelWithDebInfo，单线程 CPU 0、powersave、允许 Turbo、接电/平衡模式，
对齐热缓存、最短预热 0.2 秒、最短测量 0.5 秒、重复 5 次。
不是所有维度/CPU 的最低性能承诺，也不是端到端 QPS 倍数。

P1 perf 证据支持将分析重点放在大数组距离扫描内核中的加载与计算交互，
但没有证明 DRAM 带宽饱和，也没有证明已达到 roofline；通用缓存事件比值不等于所有缓存访问的统一未命中率。
BuildArena 暂未接入实际索引构建，没有索引构建加速或内存节省的实测结论。

自动派发后的 SIFT1M 严格 Recall@10=0.999300，P0 原目标 1.0 继续标记未达成。
该端到端数据早于对齐存储/BuildArena 的后续提交，不将它冒称为本次集成提交的重新全量评测。
等距差异说明保留原 P0 诊断结论，不为追平官方平局选择改检索逻辑。

完整性能数字和各轮环境见 [微基准记录](../../bench/README.md)、[perf 记录](../../bench/perf.md)。
