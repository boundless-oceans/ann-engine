# P2 阶段验证：HNSW 全量 SIFT1M 与 efSearch 曲线

日期：2026-10-23。当前已验证主要单机指标，尚未完成同条件 Faiss 对照，不将整个 P2 标记完成。

## 实现与正确性

图存储、随机层数、只读分层搜索、基础插入、多样性选邻与反向超限裁剪已实现。最近 M 基线与剪枝版本已在10万条子集同轮对照；本轮核心算法未改，扩展的是同图扫描与CSV评测入口。

GCC11.4 rel/san各138项通过（137个GoogleTest单元用例+1个CLI集成检查）。本轮沙盒san使用detect_leaks=0，完整日志无ASan/UBSan告警；用户随后报告普通终端默认san的138项全部通过（4.52秒），代理未另行复核该次完整日志。

CLI检查覆盖列表解析、只建图一次、重复ef召回一致、单值与扫描一致、CSV参数/元数据及非法输入。未新增真实并发、TSan、全局分配器拦截或真实OOM故障注入验证。

## 全量测量

数据为完整SIFT1M：1000000×128，全部10000条查询，k10，L2，官方groundtruth，严格ID Recall；未截断、未改平局规则。M16、Mmax0=32、efConstruction200、seed42，一次建图依次测efSearch16/32/64/128/256。

环境：Intel Core i7-14650HX（16物理核/24逻辑CPU）、Ubuntu22.04、GCC11.4、RelWithDebInfo、AVX2Four，单线程固定CPU0（P核）；阶段快照均为powersave、允许Turbo、接电，电源模式未确认，实际频率/温度未采样。每个ef独立预热1轮、正式3轮，额外一轮召回不计QPS。顺序固定，没有跨种子重复建图或置信区间分析。Search内部局部工作区成本计入查询。

建图305.710s，索引申请容量684722880字节（684.7MB / 653.0MiB），最高层5，L0平均出度21.11。进程峰值RSS约1146.1MiB，包含原始数据集与临时空间，不能与索引容量混用。
