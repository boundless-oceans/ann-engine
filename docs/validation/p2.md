## Python Faiss 同轮对照

基于提交57a2591的自研程序和新增Python脚本，完整SIFT1M、官方groundtruth、M16/Mmax0=32、efConstruction200、seed42、efSearch16/32/64/128/256。先自研后Faiss，18:09:51–18:22:28（UTC+8）。i7-14650HX16核/24CPU，双方单线程CPU0；所有阶段快照powersave、允许Turbo、接电，实际频率/温度、电源模式及背景负载未完整采样。没有随机化顺序、跨种子重复或置信区间。

Faiss使用venv中的1.12.0 AVX2 wheel、Python3.10.12、NumPy2.2.6，-I隔离ROS的PYTHONPATH。双方每次查1条，Faiss公开Python包装开销包含在计时中，D/I输出预分配；不估算扣除开销。每ef独立预热1轮、正式3轮，另查1轮统计严格Recall。

默认ef64的自研/Faiss QPS为6661.7/6986.6，严格Recall为0.963770/0.970530，P99为0.208726/0.201167ms；五个ef点的吞吐比均超过60%。两者RNG、插入顺序与图不同，同参数不等于同准确率，不能把95.3%当作纯原生内核比值。

自研申请容量684722880字节；Faiss可见数组有效字节656255596，不含剩余容量和对象开销。两者口径不同，不计算内存节省比例。Faiss构建351.605s，自研304.232s；这些是本轮参数和环境下的观测，不外推其他构建或机器。
