# P3：KMeans 与未量化 IVF 阶段验证

日期：2026-10-23。分支：`feat/p3-ivf-and-quantization`，基于 P2 合并提交 `045f26b`。KMeans 块已由用户提交为 `63a9a52` / `49f661f`；当前 IVF 功能分支为 `feat/p3-ivf-flat`。

## 范围

实现 `include/ann/kmeans.h`、`src/kmeans.cpp`，沿用设计中的公开签名。L2 k-means++ 初始化、固定次数 Lloyd 更新、空簇最远样本重置；private `src/kmeans_internal.h` 只供实现与定向测试使用。最后重算分配，使 `ClusterSizes()` 对应实际输出质心。未实现 IVF、SQ/PQ 或 P3 数据集性能验收。

输入有限，Train 要求 n>=k，构造要求 dim/k/iters 为正、簇 ID 可由 uint32_t 表示。距离/均值 double 累加，输出 float；等距取较小簇 ID。重复样本允许最终空簇。Train 成功后提交输出、统计和随机状态，失败保留已有结果；没有实际 OOM 注入。Assign 不修改成员，Train 不允许与同实例其他操作并发。
