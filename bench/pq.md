## 命令与口径

```bash
./build-rel/bin/ann_bench --index ivf --quantizer pq \
  --data data --max-base 10000 --nlist 32 --kmeans-iters 5 \
  --pq-m 32 --pq-ksub 256 --nprobe-list 1,4,16,32 \
  --k 10 --metric l2 --seed 42 --warmup 1 --runs 3
```

此例的data目录使用全部磁盘查询；本轮实际使用前100条查询视图，制备方法见[IVF/SQ8评测](ivf.md)的sq8_result_dir/workload。--nq只控制合成查询，不能用--nq 100截断--data。

- --quantizer仍默认none，新增pq，与sq8均只适用IVF/L2；不改变原Flat/HNSW命令。
- --pq-m默认16，必须整除实际加载维度；--pq-ksub默认256，范围1..256，样本数不得少于ksub。不自动缩小码本或padding。
- --pq-m/--pq-ksub只允许配合--quantizer pq，不能复用HNSW的--m。
- --kmeans-iters只控制IVF粗聚类；PQ每段固定25轮，种子seed+s。同一个数值种子不代表与Faiss得到相同中心。
- 一份索引扫描多个nprobe，各点独立预热/正式计时，另查一轮计算召回。构建包含Add/粗训练/PQ训练/编码，不含文件加载和Flat参考计算。
- CSV保留原31列，追加pq_m,pq_ksub为33列；非PQ这两列为0。code_size/lut_floats从量化器读取，不再把dim当作PQ码长；none为0/0，SQ8为dim/(dim×256)，PQ为m/(m×ksub)。旧CSV不改，按列名读取仍兼容，固定列数读取器需适配。
- PQ粗路由可用AVX2Four，候选为标量ADC；LUT仍逐非空列表重建且两遍检查/填表，全部成本计入查询，不称为全程AVX2。

在上一节创建的查询前缀视图上复现起步扫描：

```bash
for m in 16 32; do
  taskset -c 0 ./build-rel/bin/ann_bench \
    --index ivf --quantizer pq --data "$sq8_result_dir/workload" \
    --max-base 10000 --nlist 32 --kmeans-iters 5 \
    --pq-m "$m" --pq-ksub 256 --nprobe-list 1,4,16,32 \
    --k 10 --metric l2 --seed 42 --warmup 1 --runs 3 \
    --csv "$sq8_result_dir/pq$m.csv" \
    > "$sq8_result_dir/pq$m-console.txt" 2> "$sq8_result_dir/pq$m-progress.txt"
done
```

需要同轮比较时，同样在该视图、同CPU/参数运行none与sq8；只移除PQ专用参数。环境需按ivf.md保存，包括CPU、编译器、频率调节、电源和日期。不同时启动多个测量进程。

## 重建与排序诊断（2026-10-26）

新增独立目标 `ann_pq_diag`，不改索引、量化算法或公开接口。它在同一数据上分别构建真实 IVF-PQ，以及通过公开 KMeans/PQ 组合的分解参考；后者按原始 ID 保存代码，绕开 IVF 的 CSR、代码寻址、候选遍历和结果堆。全探测条件下比较三条路径：

1. IVF-PQ 的实际 top-k。
2. 分解参考逐列表建 LUT、逐向量 ADC、全排序。
3. 解码残差后直接用 double 累加距离、全排序，不查 LUT。

第一、二条应返回逐位置相同 ID 和逐位相同 float 距离；第二、三条报告距离相对误差和排序差异。double 对照在 `float(q-c)` 与解码残差之间计算，沿用实际查询残差舍入，不将 float 表的舍入误差混入编码误差。相对误差分母为 `max(1, double_distance)`，超过2e-6或实际 IVF/穷举ADC不一致时退出非零。解码排序可能因 float 平局换序，单独报告，不直接作为退出失败条件。

此外，工具统计 `Decode(Encode(r))-r` 在残差空间的逐坐标 MSE、分段 MSE，以及总平方误差/原残差总平方能量。原向量上的 FlatIndex 重算严格 ID 参考，并统计丢失精确近邻的 ADC 排名；这不是官方百万库答案，也不是容差 Recall。仅打印最先遇到的10个丢失样例，完整汇总覆盖全部100查询。
